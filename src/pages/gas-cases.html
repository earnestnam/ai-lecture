사내에서 돌아가는 자동화들

어떤 자동화든 6칸으로 표현됩니다. 단순한 알림봇도, 복잡한 AI 페르소나봇도 — 구조는 같고, 복잡도의 차이는 각 칸의 두께에서 드러납니다.

CASE 01 회의록봇

회의를 하는 모든 직무

Gemini 회의록을 Claude가 재구조화하고, 참여자에게 슬랙 DM으로 자동 전송

CASE 02 슬랙 요약봇

슬랙을 쓰는 모든 직무

긴 스레드에 이모지 반응 하나면 1줄 요약 + 결정사항 + 액션 아이템이 3초 만에

CASE 03 HR 자동화 맵

HR + 모든 부서가 같은 패턴

D-Day 기반 트리거 + 마스터 시트 + 슬랙 워크플로 — 정해진 시점에 정해진 사람에게

CASE 04 의사결정권자봇

보고·검토를 하는 모든 직무

문서 링크를 DM으로 보내면 8~20초 안에 페르소나 기반 5단 피드백

Case 01 — 회의록봇 (단순한 것도 6칸)

01 시작 방식
회의 종료 후 회의록 메일 계정이 캘린더 이벤트 첨부 파일 확인
시간 트리거
02 INPUT
Gemini 회의록 스크립트
+ 캘린더 이벤트 정보
(제목·참여자·반복여부)
03 OUTPUT ✦ AI
원하는 구조로 재요약된 회의록
+ 정기회의 1일 전 리마인드
04 커뮤니케이션
참여자별 슬랙 DM
(이메일 → 슬랙 ID 매핑)
05 데이터 관리
회의록 시트 기록
(회의명·일자·참여자·요약·링크)
06 연동 서비스
Calendar + Meet + Gemini
+ Email→SlackID 매핑
+ Slack DM API + Drive
"AI를 부르는 곳은 한 군데 — '재요약'할 때만. 나머지는 다 GAS가 처리합니다."

회의록봇 동작 흐름 (타임라인)

1

회의 종료 (Google Meet)

Gemini가 자동으로 회의록 생성 → 회의록 메일 계정으로 전송

2

GAS 시간 트리거 실행 (5~10분 후)

메일 계정에서 회의록 수신 확인 → 캘린더 이벤트 정보 조회 (제목·참여자·반복여부)

3

Claude API 호출 — 재요약

Gemini 원본 + 캘린더 정보 → Claude가 구조화된 회의록으로 재정리

4

이메일 → 슬랙 ID 매핑

참여자 이메일 목록 → SlackID 매핑 시트에서 VLOOKUP → 개인 DM 발송

5

회의록 시트 기록 + (선택) 리마인드 예약

정기 회의는 다음 회의 1일 전 리마인드 자동 예약

🔑 이메일 → 슬랙 ID 매핑

이 하나가 전사 자동화의 열쇠. 이 테이블 하나면 누구에게든 메시지를 보낼 수 있습니다.

Case 02 — 슬랙 요약봇 (긴 스레드, 3초 만에 따라잡기)

핵심 기능

  • 1줄 요약 + 결정사항 + 액션 아이템
  • 담당자 개별 멘션해서 진척 요청
  • 스레드 길이 제한 없음 (100개+ OK)
  • 이미지까지 분석 (멀티모달)

정책과 함께 설계됨

DM은 막아둠 — 채널 커뮤니케이션 정책상 채널만 가능. 자동화와 정책이 같이 설계된 사례.

6칸 요약
시작 방식 채널 내 이모지 반응 (이벤트 트리거)
INPUT 슬랙 스레드 전체 + 이미지
OUTPUT 요약 + 결정사항 + 액션 아이템 + 멘션
커뮤니케이션 같은 채널 스레드 답변
데이터 관리 별도 저장 없음
연동 Slack API + Claude API

Case 03 — HR 자동화 맵 (정해진 데이터 + 정해진 시점 + 정해진 사람에게)

공통 패턴

D-Day 기반 + 마스터 시트 + 슬랙 워크플로

이 3개가 보이면 자동화의 자리.

"HR에만 적용되지 않습니다 — 영업의 KPI 알림, 재무의 마감 리마인드, 운영의 장애 대응 절차 — 다 같은 패턴입니다"

📅

수습 평가 D-30

담당자에게 미리 알림

📅

계약 만료 D-90

갱신 검토 요청 자동 발송

📅

연간 목표 설정 시즌

개인별 맞춤 안내문 발송

Case 04 — 의사결정권자봇 (복잡한 것도 6칸)

회의록봇은 '요약'이 전부였습니다. 실제 업무에서 필요한 건 단순 요약이 아니라 — 나처럼 생각하는 리뷰어입니다.

01 시작 방식
슬랙 DM 메시지 또는 채널 멘션
입력 트리거
02 INPUT
텍스트 + Google Docs/Sheets/
Slides 링크 + PDF + 이미지
+ 대화 맥락
03 OUTPUT ✦ AI
페르소나 기반 5단 피드백
(요약 / 잘된점 / 개선 / 질문 / 관점)
04 커뮤니케이션
슬랙 스레드 답변
8~20초 응답
05 데이터 관리
스레드 내 대화 맥락만 유지
별도 저장 없음
민감 주제 차단
06 연동 서비스 주목
Slack + Google Drive
+ AI 모델 라우팅 (질문 분류)
+ GAS
+ 특정 기간 슬랙 대화 분석 (페르소나 구성)
"어디까지 갈 수 있는가? — 6칸을 잘 채울 수 있는 만큼."
💡 6칸의 두께가 복잡도입니다

회의록봇의 연동 서비스 칸은 4줄, 의사결정권자봇은 5가지 서비스. 처음엔 연동 서비스가 1~2개인 단순한 것부터 시작하세요.
