GAS(Google Apps Script)란?

무엇인가

Google Drive 안에서 실행되는 자바스크립트 환경입니다. 브라우저에서 바로 작성하고 실행할 수 있습니다. Excel 매크로의 강화판이라고 생각하면 됩니다.

핵심 장점

  • ✦ 별도 서버 설치 불필요 — 구글이 실행해줌
  • ✦ 시간/이벤트 트리거 내장
  • ✦ Claude Code가 코드를 대신 작성해줌

AI 엔진 역할 — Claude vs Gemini

자동화에서 하는 역할

  • ✦ 요약 — 긴 회의록, 슬랙 스레드를 구조화
  • ✦ 분류 — 질문 유형, 우선순위 판단
  • ✦ 피드백 — 문서, 보고서에 대한 구조적 리뷰
  • ✦ 코드 작성 — GAS 자동화 스크립트 생성

Claude vs Gemini 선택 기준

Claude

긴 문서 이해·추론에 강점, 한국어 지원 우수

Gemini

Google Workspace 친화적, Sheets 데이터 처리에 유리

GAS — Claude API 호출 예시 
// GAS에서 Claude API 호출
function callClaude(prompt, data) {
  const apiKey = PropertiesService
    .getScriptProperties()
    .getProperty('CLAUDE_API_KEY');

  const response = UrlFetchApp.fetch(
    'https://api.anthropic.com/v1/messages', {
    method: 'post',
    headers: {
      'x-api-key': apiKey,
      'anthropic-version': '2023-06-01',
      'content-type': 'application/json'
    },
    payload: JSON.stringify({
      model: 'claude-sonnet-4-6',
      max_tokens: 1024,
      messages: [{ role: 'user', content: prompt + '\n\n' + data }]
    })
  });

  const result = JSON.parse(response.getContentText());
  return result.content[0].text;
}
💡 AI를 부르는 시점은 딱 한 단계

전체 흐름에서 AI 호출은 한 곳만입니다. Claude나 Gemini 중 하나를 선택해 프롬프트를 던지고, 나머지는 GAS가 처리합니다. AI 호출을 최소화할수록 속도도 빠르고 비용도 줄어듭니다.

⚠️ API Key는 코드에 직접 쓰지 마세요

API Key를 소스 코드에 하드코딩하면 GitHub 등에 올렸을 때 유출될 수 있습니다. 반드시 Script Properties에 저장해야 합니다. 저장 방법은 다음 페이지에서 자세히 다룹니다.
